# Sentinel Lite Fictional Compliance Policies

| Chunk ID | Policy Rule | Text |
| :--- | :--- | :--- |
| **P1.1** | Restricted Country Prohibition | Vendors based in a Restricted Country (Zorvania, Kelmarra) must not be onboarded. |
| **P1.2** | Allowed Country Clearance | Vendors based in any other country may proceed to further checks. |
| **P2.1** | Physical Goods Insurance Requirement | Vendors supplying physical goods must hold liability insurance of at least 500,000 USD. |
| **P2.2** | Software Liability Insurance Requirement | Software-only vendors must hold liability insurance of at least 100,000 USD. |
| **P3.1** | Data Privacy Certification Requirement | Vendors that handle personal data must hold a valid DATASAFE-2 certificate. |
| **P3.2** | Certification Expiry Limit | A certificate must not be expired on the submission date. |
| **P4.1** | Code of Conduct Compliance | Every vendor must have signed the Code of Conduct. |
| **P4.2** | Anti-Bribery Compliance | Vendors with a bribery finding in the last 5 years must be rejected. |
